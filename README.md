# PEAK-NoClip
Mod NoClip game PEAK
Этот мод даст вам возможность при нажатии F3 включать NoClip


## 🚀 Инструкция по установке:
1. Перейдите в раздел **Releases** в правой части этой страницы и скачайте актуальный `.zip` архив.
2. Распакуйте содержимое архива прямо в **корневую папку игры** (туда, где лежит файл `PEAK.exe`).
3. При нажатии на F3 вы включаете NoClip при нажатии на + или - меняется скорость. Управление WASD Cntr SPACE 
4. Наслаждайтесь

*Разработано с использованием BepInEx и Harmony.*

Mod NoClip game PEAK
This mod will give you the ability to enable NoClip by pressing F3.

## 🚀 Installation instructions:
1. Go to the **Releases** section on the right side of this page and download the latest `.zip` archive.
2. Unpack the contents of the archive directly into the **game’s root folder** (the folder where the `PEAK.exe` file is located).
3. When you press F3, you enable NoClip; when you press + or -, the speed changes. WASD Cntr SPACE Management 
4. Enjoy

*Developed using BepInEx and Harmony.*
